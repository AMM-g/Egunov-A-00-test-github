# Правила проекта

- Проект используется для проверки работы Git с репозиторием AMM-g/test.
- Основная ветка — `main`, удалённый репозиторий — `origin`.
- Храни входные материалы в `inputs/`, рабочие файлы в `work/`, документацию в `docs/` и готовые результаты в `deliverables/`.
- Перед отправкой проверяй содержимое коммитов и не включай секреты или локальные настройки.
